# Data Availability Statement — corrected archive

The source code, ontology, synthetic IFC fixtures, 72-case mutation protocol and corrected recorded experimental results supporting the controlled synthetic experiment are available in the project repository (https://github.com/Amirh18/change-aware-bim-compliance). The corrected version (v1.1.0) is publicly available at https://doi.org/10.5281/zenodo.24518101. The earlier v1.0.0 record (https://zenodo.org/records/24406900) does not contain the corrected implementation and results.

The public package does not contain the third-party IFC model used in the separate large-model evaluation, because authorization for public redistribution has not been established. The separate saved-IFC experiment is not independently reproducible from the synthetic fixtures. Regulatory applicability has not been independently validated.
